# Design System - Kanno

## Warna
- Primary: #1a1a1a (hitam)
- Secondary: #ffffff (putih)
- Accent: #d4a574 (coklat emas)
- Background: #fafafa (abu sangat muda)

## Typography
- Font Heading: 'Playfair Display', serif
- Font Body: 'Inter', sans-serif
- Heading sizes: 48px (h1), 36px (h2), 24px (h3)

## Spacing
- Small: 8px
- Medium: 16px
- Large: 32px
- XL: 64px

## Breakpoints
- Mobile: < 768px
- Tablet: 768px - 1024px
- Desktop: > 1024px
